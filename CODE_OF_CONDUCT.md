# Code of Conduct

NET-TRV follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep
discussions about the project. Harassment, insults and personal attacks are
not accepted in issues, pull requests or discussions.

## Enforcement

Report unacceptable behaviour privately to the maintainer,
[@kingpainter](https://github.com/kingpainter), through GitHub. Reports are
handled confidentially. The maintainer may edit or remove comments and block
participants who break this code of conduct.
